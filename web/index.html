    Imported files go to Documents (File > Open shows them). Save sketches to Documents to download them here. Everything you save stays in this browser (IndexedDB). You can also drop files onto the page. URL options: ?resolution=1280x800, ?sound=false.

    The first start takes a while: about 100 MB to download, then Wine sets up.
